# Project Session Log

The last developer session's log, read last by `/start` for continuity. It's opened (`(open)`)
before the session's first task and gets a line after every finished task, so it stays current
even if the session ends without `/end`. `/end` completes it and marks it `(ended)`. Before a new
session's log replaces this one, anything durable is moved into `CURRENT_STATE.md`.
