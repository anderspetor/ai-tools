# Design

HTML mockups of the application's UI, made in `/brainstorm` sessions so the user can see and react to the design before it's built.

- One self-contained HTML file per screen or flow. Open it in a browser; no internet needed.
- The approved mockups are linked from `Instructions/manuscript/UI.md`. Where a mockup and `UI.md` disagree, the text in `UI.md` wins.
- Mockups are the visual target for the real UI, not starter code. The developer builds the UI in `Application/`, in the application's own technology.
- Files named `draft-….html` are alternatives the user kept but didn't approve. Don't build from them.
- References the user brings (screenshots, example apps, colours) go in `Source-files/`, not here.
